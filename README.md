# 🎮 Jogo da Velha (Tic Tac Toe)

Um jogo simples de Jogo da Velha desenvolvido em Python onde você joga contra a IA do computador.

## 📋 Funcionalidades

- Jogue contra a IA do computador
- Interface de linha de comando com saída colorida
- Validação de entrada
- Contador de movimentos

## 🚀 Como Executar

1. Certifique-se de ter Python 3.x instalado
2. Instale as dependências:
   ```bash
   pip install colorama
   ```
3. Execute o jogo:
   ```bash
   python Jogo_da_Velha.py
   ```

## 📖 Como Jogar

1. O tabuleiro do jogo é uma grade 3x3 com coordenadas (0-2 para linhas e colunas)
2. Digite o número da **linha** e da **coluna** para colocar sua marca (X)
3. O computador jogará automaticamente como (O)
4. O primeiro a conseguir 3 em uma linha vence!

## 🛠️ Tecnologias

- Python 3.x
- Colorama (para saída colorida no terminal)
